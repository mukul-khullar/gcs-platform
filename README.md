# MAVLink Ground Control Station & Companion Intelligence Layer

Custom MAVLink ground control station with a companion-computer intelligence layer built for ArduPilot SITL simulation.

## Quick Start

1. Clone the repository and bootstrap the environment:
   ```bash
   git clone https://github.com/mukul-khullar/gcs-platform.git gcs-platform && cd gcs-platform
   make bootstrap
2. Start the stack and verify:
docker compose up -d
docker compose ps
EOF
